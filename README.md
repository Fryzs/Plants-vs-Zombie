# Plants vs Zombie

Навчальна гра в жанрі «tower defense» на Windows Forms (.NET).

## Як грати

- Поле поділене на ряди, по яких до будинку йдуть зомбі.
- Оберіть рослину й клацніть на клітинку, щоб посадити її:
  - **соняшник** — дає сонечка (ресурс для садіння);
  - **горохострил** — стріляє горошинами по зомбі в своєму ряду.
- Рослини мають здоров'я, і зомбі можуть їх з'їсти.
- Якщо зомбі дійдуть до кінця поля — гра програна.

У грі є фонова музика та звукові ефекти (через NAudio і `SoundPlayer`).

## Запуск

1. Відкрийте `Plants vs Zombie.sln` у Visual Studio і відновіть NuGet-пакети (NAudio).
2. Шляхи до звукових файлів у `Form1.cs` і `Form2.cs` прописані абсолютно — за потреби замініть їх на свої.
3. Натисніть F5.
